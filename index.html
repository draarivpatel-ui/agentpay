A Spending Policy And Audit Console For AI Shopping Agents

AgentPay sits between your autonomous shopping agent and PayPal. The agent proposes purchases, a deterministic policy engine scores every proposal, and each decision lands in an approval queue and a tamper evident audit trail. Checkout is simulated end to end, so no live funds ever move.

Policy Studio

Set per merchant limits, category rules, amount ceilings, velocity caps, time windows in UTC hours, and minimum trust tiers. Changes apply to the next agent run, and every change is appended to the audit trail.

Simulated Shopping Agent

Atlas is a scripted shopping agent, not a live model. Each run proposes purchases drawn from a synthetic catalog with a fixed seed, and every proposal is scored before it can reach the approval queue.

Approval Queue

Proposals wait here until a human decides. Approving runs the simulated checkout stub and writes an Approved row to the ledger. Rejecting writes a Blocked row. Both append audit entries with before and after states.

Transaction Ledger

Every synthetic and session transaction in one table. Sort columns, filter by text and number, and drag column headers into the group panel to group rows. The table loads AG Grid Community from a CDN, and falls back to a built in table with the same core abilities when the CDN is unreachable.

Loading the ledger table.

Audit Trail

Append only and hash chained. Each entry stores who acted, what changed, and the before and after states. The chain is reverified on every render. The hash is FNV 1a, chosen for determinism in a demo, not for cryptographic strength.
